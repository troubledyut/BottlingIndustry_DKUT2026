# Object Handling

Gripping, material unit manipulation, cutting, and physics-based object handling demos.

## Scenes

| Scene | Description |
|-------|-------------|
| DemoChangeMU | Dynamic material unit type changes during simulation |
| DemoCutter | Cutting operations on transport objects |
| DemoGrippingAdvanced | Advanced gripping with kinematic hierarchies and multiple grip types |
| DemoGrippingSimple | Simple pick-and-place demos with SCARA robot |
| DemoPhysics | Physics-based object interaction and collision |
